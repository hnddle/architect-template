# 결정 대기 · 미확인 (TODO)

> **문서 코드**: `Q` — `Q-NNN` (결정 대기 질문). 결정은 `D-NNN`
> **작성일**: YYYY-MM-DD · **최종 개정**: YYYY-MM-DD

이 문서는 요구사항 계층을 만들며 **결정하지 않고 남긴 것**이다. 입력 자료 간 차이는 A/B 원문 위치를 병기하고, 결정은 사용자 몫이다. 결정되면 「후속 수정 위치」의 문서를 고치고 결정 질문 칸에 취소선을 긋고 상태 칸에 `<결정 상태> YYYY-MM-DD (D-NNN)`을 단 뒤 CHANGELOG에 남긴다. **행은 지우지 않는다** — 미결이 있었다는 사실도 기록이다.
