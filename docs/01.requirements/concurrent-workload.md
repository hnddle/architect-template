# 동시 처리 업무 (Concurrent Workload)

> **문서 코드**: `FDW` — 건수 · ID 범위는 [README §1](README.md#1-문서-지도)
> **원문**: <조사 §n · 데이터 §n>
> **연관**: [current-workflow.md](current-workflow.md) · [pain-points-amplifiers.md](pain-points-amplifiers.md)
> **작성일**: YYYY-MM-DD · **최종 개정**: YYYY-MM-DD

동시 처리 업무는 핵심 흐름([current-workflow.md](current-workflow.md))과 **같은 사람이 같은 시간에** 처리해야 하는 주변 업무다. 핵심 흐름의 단계로 세지 않지만, 이것들이 겹치는 만큼 핵심 흐름의 비용이 곱해지므로 증폭 요인(`PNA`)의 정량 근거가 된다.
