> **원자료**: `<원문 파일 이름>` · `screen-01` ~ `screen-<nn>`
> **전제**
> - 참고 시스템은 **재구축 대상이 아니라 관찰 자료**다. 참고 시스템에 없는 것은 결함이 아니라 관찰 사실이고, 원문과 다른 지점은 고객사별 편차의 신호다.
> - 표본: 원문 <n>건 + 참고 시스템 <n>건
>
> **표기**
> - **[원문]** 원문 내용. 문장을 바꾸지 않고 그대로 옮김
> - **[관찰]** 화면에서 직접 확인한 것. 추측이 아닌 화면에 보이는 것만
> - **[조사 항목]** 원문과 참고 시스템이 다르거나 어느 쪽에도 근거가 없어 사용자 조사로 확인할 것. 여기서 결정하지 않는다
